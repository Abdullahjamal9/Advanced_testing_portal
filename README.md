# 🧪 Advanced Testing Portal

An enterprise-level **Testing, Evaluation, and Certification Management System** designed to automate employee assessments, manage standards-based exams, handle practical evaluations, and generate dynamic certificates using templates.

---

## 🚀 Key Highlights

- 🧑‍💼 Dual-role system (Admin + Employee)
- 📝 Online testing with skip/review functionality
- 📊 Admin analytics dashboard with charts and stats
- 🧾 Automated certificate generation system
- 📚 Standards-based evaluation framework
- 🧪 Theory + Practical combined scoring system
- 🤖 Auto-grading system with negative marking (0.25)
- 📎 Attachment-based result verification
- ❓ Bulk question management system

---

## 👤 Employee Flow

1. Login using Employee ID  
2. Select Standard / Subject  
3. Start Test  
4. Skip or answer questions  
5. Submit test  
6. Auto evaluation performed by system  

---

## 🧠 Auto-Grading System

- Automatic evaluation of submitted tests  
- Negative marking applied (0.25 per wrong answer)  
- Passing percentage defined per standard  
- System automatically:
  - Calculates final score  
  - Determines pass/fail status  
  - Updates result dashboard  
  - Triggers eligibility for certificate/practical test  

---

## 🛠️ Admin Panel Features

### 📊 Dashboard
- Performance analytics (charts & stats cards)
- Top 10 recent results
- System overview

### 📄 Results Management
- Filter results by name, ID, standard, status, date
- View results with graphs + tables
- Download answer sheets
- Edit / delete results
- Manual result entry
- Attach external verification files

### 🧪 Practical Evaluation
- Identify eligible candidates
- Add practical scores
- Combine theory + practical for certification

### 📚 Standards System
- Add / edit / delete standards
- Set passing percentage per standard
- Attach certificate templates
- Template controls certificate format
- Certificate number generated from template filename

### 🎓 Certificate Module
- Auto certificate generation
- New certification + recertification support
- Links previous certificate history
- Auto-generated certificate numbers

### ❓ Question Bank
- Bulk upload / download
- Bulk delete
- Individual question editing
- Advanced filters

### 👥 Employee Management
- Add / update / delete employees
- Maintain structured database

### 📎 Attachments System
- Upload supporting documents
- Used for manual/verified results
- Download anytime for audit

---

## ⚙️ System Architecture

Employee Login → Test Attempt → Auto Grading (Negative Marking) → Result Evaluation → Admin Review → Practical (if required) → Certificate Generation
